# EcommerceHelper

Project scaffold for a JavaFX desktop application (MVC) connected to MySQL.

Structure created automatically. Use an IDE (IntelliJ/VS Code with Java extensions) to import as a Maven project.

Notes:
- Adjust JavaFX platform classifier in the pom if needed for your OS.
- Main class: `com.ecommercehelper.Main`

Next steps:
- Implement controllers, services and DAOs.
- Configure DB connection in `DBConnection.java` and place `ecommerce_schema.sql` into `resources/database`.
